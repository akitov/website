# Blog posts

Drop a new `.md` file in this folder to publish a post. Filename = URL slug.

## Frontmatter

```yaml
---
title: Post title (omit for quote-type posts)
date: 21.03.2013          # DD.MM.YYYY — used for sort + display
type: lesson              # quote | lesson | event
category: Life            # category pill
excerpt: Short summary    # shown on the homepage card
image: /blog/images/x.jpg # optional thumbnail
quote: "..."              # required for type=quote
author: Author name       # required for type=quote
source: Source URL        # optional for type=quote
---

Markdown body goes here.
```

## How discovery works

1. `home.js` first tries `/blog/manifest.json` (generated by `scripts/regenerate.mjs`).
2. If that fails it falls back to parsing the Python `http.server` directory
   listing — so new posts show up in dev without needing to re-run the script.

The GitHub Action `.github/workflows/reindex.yml` re-runs the regenerate script
on every push to `blog/**`, so the deployed site always has a fresh manifest
plus per-slug pre-rendered pages at `/<slug>.html`.
